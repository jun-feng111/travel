# 旅行志 · 产品需求与开发规划（v2）

> 主题：旅行分享网站。用户可按城市查看**热门景点 / 旅游攻略 / 美景 / 美食**，并额外获得**行程规划、互动地图、收藏、实用工具箱**等现代旅游产品能力。
> 纯前端、不用后端、人人可访问（Cloudflare Pages 部署）。本文档为需求说明 + 开发蓝图。

---

## 1. 产品定位

- 类型：个人旅行网站（内容展示 + 轻交互工具）
- 受众：所有能联网的访客（浏览无需登录；收藏存本地）
- 核心价值：帮用户"去哪玩、玩什么、吃什么、怎么安排、带什么"
- 风格：清新治愈、图文并茂、移动端优先、响应式

---

## 2. 竞品调研结论（2026-08-03，来自网络调研）

调研对象：马蜂窝、携程、Dream Trip、Faroway、Wanderlog、Google Maps、Splitwise、PackPoint 等 2026 主流旅游 App/网页。

**主流产品共性功能**：目的地浏览、景点详情、攻略、美食、图集、搜索、（AI）行程规划、互动地图、收藏心愿单、游记社区、最佳季节/天气、实用工具（汇率/打包/预算）、多语言。

**我们现有 vs 缺口**：城市浏览/景点/攻略/美食/图集/搜索 已具备；**缺 AI 行程规划、互动地图、收藏、实用工具箱、结构化最佳季节**。

**本轮新增（纯前端可实现、契合定位）**：① 行程规划器 ② 互动地图 ③ 我的收藏 ④ 旅行工具箱（预算计算 + 打包清单）。

## 5. 数据模型（扩展）

在原有 `cities/spots/guides/foods/galleries` 基础上新增：

```jsonc
// city 增加
{ "bestSeason": "3-5月、9-11月", "weather": "亚热带湿润，春秋最宜" }

// spot 增加（供地图打点）
{ "lng": 104.06, "lat": 30.67 }   // 经纬度，无真实值时用城市中心近似

// planner 算法输入（不持久化）：{ cityId, days, budget, style: '休闲'|'深度'|'亲子'|'美食' }
// 输出：[{ day:1, items:[{type:'spot'|'food', id, name, note}] }]
```

## 6. 技术选型（已确认）

- **前端**：Vue 3 + Vite + Vue Router(hash) + Element Plus(按需)
- **地图**：Leaflet + OpenStreetMap 免费瓦片（CDN 引入，无需 Key）
- **收藏**：浏览器 localStorage（无后端）
- **内容**：静态 JS（`src/data/`）
- **部署**：Cloudflare Pages（`public/_redirects` 已配）
- **不用后端**、**不接真 AI**（行程规划用前端算法基于现有数据）

---

## 7. 本轮新增功能设计

### 7.1 行程规划器 `/planner`
- 表单：选择城市、天数(1-7)、每日预算(元)、风格(休闲/深度/亲子/美食)
- 算法：按风格给景点/美食加权打分，贪心排进每天，控制每日预算与时长，输出逐日行程卡片
- 每条目可"加入收藏"
- 结果可"在地图上查看"（跳 `/map/:cityId` 并高亮）

### 7.2 互动地图 `/map/:cityId`
- Leaflet 初始化城市中心，遍历该城 spots 打 marker
- 点击 marker 弹 InfoWindow：封面(占位)+名称+评分+简介+"查看详情"链接
- 无经纬度时用城市中心 + 轻微偏移散开

### 7.3 我的收藏 `/favorites`
- 任意城市/景点/美食卡片有"♡ 收藏"按钮 → 存 localStorage（key: `travel_favs`）
- 收藏页分类展示，可取消；顶部实时计数
- 全局收藏数显示在导航栏

### 7.4 旅行工具箱 `/tools`
- **预算计算器**：输入天数、人数、各项日均预估(住宿/餐饮/交通/门票/购物)，实时算总预算与人均
- **打包清单生成器**：选目的地类型(城市/海岛/山区/亲子)+ 天数 + 季节，生成情境化清单（可勾选已完成）
